What comes out

  • Calibrated parameters, with 95 % intervals from the Jacobian and from a bootstrap. A parameter the measurements cannot determine is reported not estimable, with the reason, instead of a number that looks precise.
  • Before / after: the model with your starting values and with the calibrated ones, against every measurement, and the residuals.
  • Validation on measurements the fit never saw (or the last ones, as an extrapolation test).
  • Other estimators on the same data (Bayesian, autodiff, adjoint, physics-informed network), ranked by held-out error.
  • Downloads: report, StudyResult and ModelRef contracts, CSV tables.

Your own solver, on your machine

      
This server does not run uploaded code. To calibrate a solver you run yourself, upload a table of its runs
        here, or call the same library on your machine. CallableModel wraps any function or solver
        interface that returns the predictions at the measurement points:

      
import numpy as np
import pinneapple_analysis.inverse_problems as inv
from pinneapple_data.data_health import load_table

def run_solver(theta, inputs):                  # your solver: parameters in, predictions at the probes out
    return my_solver(h=theta["h"], k=theta["k"], probes=inputs["x_mm"])

model = inv.CallableModel(run_solver, inputs=["x_mm"], name="my solver", cost="expensive")
df, _ = load_table(open("thermocouples.csv", "rb").read(), "thermocouples.csv")
obs = inv.Observations.from_frame(df, inputs=["x_mm"], value="T_C", sigma=0.5)
params = [inv.Parameter("h", 50, 1, 2000, "W/m²K"), inv.Parameter("k", 16, 1, 500, "W/m·K")]
result = inv.calibrate(model, obs, params, holdout_fraction=0.25)
print(result.parameters, result.metrics, result.warnings)
