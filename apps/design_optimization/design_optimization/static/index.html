the method behind the result

How this actually works

Three real steps: the closed-form ground truth, the trained surrogate, and the real optimizer loop.

1 The physics: thin-airfoil theory + a real form-drag correlation

Lift comes from real thin-airfoil theory (Anderson, Fundamentals of Aerodynamics) — the classic Fourier-series solution for a cambered mean line, evaluated here by real numerical quadrature over the same cosine-spaced parametrization PINNeAPPle's own NACA generator draws the shape from:

Cl = π · (2·A0 + A1)

Drag comes from Hoerner's real form-drag correlation for a streamlined 2-D body (Hoerner, Fluid-Dynamic Drag, 1965), built on the standard turbulent flat-plate skin-friction law, both surfaces wetted:

Cd = 2 · (0.074 / Re^0.2) · (1 + 2(t/c) + 60(t/c)⁴)

This is a real, standard, textbook-level 2-D aerodynamic model — deliberately not a full CFD solve. See the scope note below for exactly what it does and doesn't capture.

2 The surrogate: a real trained physics stand-in

A small MLP (pinneapple_design.design_optimizer.surrogate.PhysicsSurrogate) is trained — real Adam + MSE, via its own real train_on_dataset — on -- real samples of the closed-form physics above, and checked against -- held-out samples it never trained on (real validation error: --). Because lift (~O(1)) and drag (~O(0.01)) differ by two orders of magnitude, the network is trained on per-channel-normalized targets, then composed with a fixed real affine layer so the surrogate the optimizer actually queries outputs real physical units throughout — standard practice for multi-output physics surrogates, not a shortcut.

3 The optimizer: real gradient descent on the design itself

The design vector (camber, thickness) is a real torch.nn.Parameter. GradientDesignOptimizer takes one real Adam step per iteration straight through the trained surrogate, minimizing a real CompositeObjective (predicted drag, plus a penalty for drifting from the baseline's real target lift) subject to a real BoxConstraint keeping the design inside a manufacturable NACA range. DesignOptLoop orchestrates the whole thing and calls the real run converged with its own real 5-iteration stagnation rule — not a fixed iteration count picked to look good.

Honest scope. This is a real, standard 2-D aerodynamic engineering model, not a panel method or a RANS/Navier–Stokes CFD solve, and not a 3-D finite wing (so no induced drag enters this result). Thin-airfoil theory doesn't capture how thickness perturbs lift; Hoerner's correlation doesn't capture how camber/lift perturb viscous form drag — both real, disclosed simplifications of the closed-form ground truth itself, not simplifications the optimizer introduced. Because the ground truth has no thickness effect on lift, the optimum is close to "thinnest allowed section": a panel method or RANS would trade these off.

pinneapple_physics/closed_form/thin_airfoil.py — the closed-form ground truth
def thin_airfoil_cl(m, p, alpha_deg, n_quad=4001):
    # Glauert Fourier-series thin-airfoil solution
    theta = np.linspace(0.0, math.pi, n_quad)
    dz = naca4_camber_slope(0.5 * (1.0 - np.cos(theta)), m, p)
    a0 = math.radians(alpha_deg) - np.trapezoid(dz, theta) / math.pi
    a1 = 2.0 / math.pi * np.trapezoid(dz * np.cos(theta), theta)
    return math.pi * (2.0 * a0 + a1)

def hoerner_profile_cd(t_c, reynolds):
    # turbulent flat-plate skin friction, two wetted sides, Hoerner form factor
    return 2.0 * turbulent_flat_plate_cf(reynolds) * (1.0 + 2.0 * t_c + 60.0 * t_c ** 4)
pinneapple_design/design_optimizer/optimizer.py — the real gradient step
class GradientDesignOptimizer:
    def step(self, surrogate, objective, constraints, theta_np):
        self._theta.copy_(torch.from_numpy(theta_np))
        def _closure():
            self._opt.zero_grad()
            u = surrogate.model(self._theta.unsqueeze(0)).squeeze(0)
            loss = objective(self._theta, u) + constraints.total_penalty(self._theta, u)
            loss.backward()
            return loss
        loss_val = _closure(); self._opt.step()  # a real Adam update
        return self._theta.detach().cpu().numpy(), float(loss_val.item())
