One datasheet, data from four places

Engineering forms and datasheets collect data that lives in other documents: the process datasheet, the mechanical datasheet, the owner's specifications, the calculations. Compiling them by hand takes hours, and conflicts between documents or missing data surface late, as questions from the vendor.

Pressure vesselASME Form U-DR-1, user's design requirements (fills the official form)
Relief valvePSV datasheet with the data of API 520 / API 526
Heat exchangerShell-and-tube datasheet with the data of TEMA / API 660, per side
Storage tankAtmospheric tank datasheet with the data of API 650
PumpCentrifugal pump datasheet with the data of API 610
  1. Read every document: tables and "label: value" lines, with units. Scanned pages go through OCR.
  2. Compile every item of the format. Each value keeps its document, page and the exact text it came from.
  3. Flag conflicts between documents and the required items nobody states, so you know whom to ask.
  4. Output the filled form or the compiled datasheet (PDF), a CSV checklist and a JSON data record for other forms and calculations.

Optionally, a local LLM served by Ollama reads what the label rules miss; documents stay on your network.
