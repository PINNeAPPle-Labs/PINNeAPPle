Public demo: only the committed workflows run here, one run at a time. Uploading your own projects and macros is for self-hosted mode.

An agent that works in the engineering software you already use, and shows its work.

A task becomes a structured workflow: steps, preconditions, the files each step must produce, the confirmations it needs, and the acceptance criteria. The agent works through each application's API first. A GUI step runs in a virtual display and is screenshotted, and every step is checked against the files it produced.

Stops when it shouldon the first failure, when an application is missing, and before expensive, overwriting, destructive or external steps until a person approves
Evidence, not claimscommands, logs, screenshots, files with SHA-256, checks; a step is passed only if it ran and its checks held
Deliversthe FreeCAD documents, the OpenFOAM case, the velocity field (CSV), images, an HTML evidence report and a StudyResult for the Evidence Report app

API

Every action of this page is a REST call; interactive documentation at /docs.

Python (PINNeAPPle)

EndpointWhat it does
GET /api/workflowscommitted workflows: inputs and bounds, steps (and whether each application is installed), criteria, limits
POST /api/interpreta sentence or JSON/YAML request to a workflow and its inputs; runs nothing
POST /api/runsstart a run (workflow + inputs, or task)
GET /api/runs/{id}live record: steps, checks, screenshots, criteria
POST /api/runs/{id}/approve, /declineanswer the confirmation a step is waiting for
GET /api/runs/{id}/report, /study_result, /bundle, /files/{path}the evidence report, the StudyResult (pinneapple_data.contracts), everything as a zip, single files
GET /api/jobs/{id}, /api/usage, /api/keysthe shared runtime: queue jobs, your use this month (runs, compute seconds, storage), API keys (X-API-Key)
Built on PINNeAPPle (pinneapple_tools.automation: workflows, adapters, runner, evidence report · pinneapple_check finite-volume balances · pinneapple_data OpenFOAM log reader). FreeCAD, CfdOF, OpenFOAM and ParaView do the engineering; the agent drives them, checks them and keeps the record.
