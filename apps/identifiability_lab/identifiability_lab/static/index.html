Parameter Identifiability Lab
Before you estimate: can these measurements determine these parameters? And which measurement would help most?

Model and experiment

Describe the model, the unknown parameters with their plausible range, and where and when you measure (with the noise). Measured values are optional: without them the analysis uses the model's own predictions at the nominal values, the usual setting when planning an experiment.

Analysis

What comes out

  • Which parameters these measurements can determine, which only in combination (and which combination), and which not at all: structural (no data could) or practical (these data cannot).
  • Four methods on the same problem: Fisher information rank and conditioning, local sensitivity, profile likelihood and a Bayesian posterior (MCMC), with the expected correlations.
  • The value of each measurement, and the extra measurements that would help most (D-optimal design): another sensor position, time, temperature or observable.
  • Downloads: the full report (JSON), a StudyResult for the other apps, CSV tables.

import numpy as np
import pinneapple_analysis.inverse_problems as inv

fin = inv.PinFinModel(d_mm=5, length_mm=50)
params = fin.default_parameters()
params[1].fixed = False                         # k unknown as well as h
plan = inv.Observations({"x_mm": [10, 20, 30, 40, 50]}, sigma=0.5,
                        observable=np.array(["T"] * 5, dtype=object))
report = inv.analyze_identifiability(fin, plan, params)
print(report.summary)
