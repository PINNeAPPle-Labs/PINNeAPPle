Pin fin

A fin on a hot wall, five thermocouples along it. The network learns the temperature profile and h from the fin equation and the readings; nobody tells it h.

What comes out

  • h, learned while the network fits the physics and the readings (watch it converge live).
  • The whole temperature profile and the heat the fin removes, from the network's own derivative at the wall.
  • A cross-check: the classical least-squares fit of the analytic fin solution to the same readings. It needs that formula; the network does not, which is why the 2D and 3D cases work too.

About 20–40 s per run on the server.

Reproduce it with PINNeAPPle

Everything on this page runs on the open-source library. Each script below is complete: install the library, save the file, run it. It prints h as it trains, then the results and the check against an independent solution. Put your own data in the block at the top (T_READ = [...] for your readings).

pip install pinneapple
python fin_h_from_thermocouples.py

The same cases with their figures and noise studies are in the repository: examples/use_cases/fin_convection_inverse.

API

Interactive documentation: /docs. A training starts a job; poll it until status is done.

MethodPathWhat it does
