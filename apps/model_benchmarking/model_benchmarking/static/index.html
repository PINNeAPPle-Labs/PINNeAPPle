the method behind the numbers

How this actually works

Three real steps, no black box in between: the problem, the architectures, the check.

1 The real problem: viscous Burgers' equation

A real, nonlinear PDE with a real closed-form reference solution (the Cole-Hopf transform, evaluated via real Gauss-Hermite quadrature) — one of PINNeAPPle Arena's 21 built-in canonical problems (burgers_1d). With ν=0.01/π and the initial condition u(x,0)=-sin(πx), this is the exact real setup from Raissi, Perdikaris & Karniadakis (2019), the paper that introduced physics-informed neural networks — a real, sharp (viscosity-limited) shock forms near x=0 around t≈0.3 and persists, making this a genuinely harder target than a smooth diffusion problem.

∂u/∂t + u·∂u/∂x = ν · ∂²u/∂x²

2 Four real, contrasting architectures

All four are real, registered entries in PINNeAPPle's ModelRegistry (94 architectures total), confirmed this session to each build as their own distinctly-named class — not a generic MLP standing in for a fancier name. (A fifth, VPINN, was tried and dropped: under this benchmark's shared training loop it builds the exact same plain MLP as Vanilla PINN — its real distinguishing feature only engages through Arena's own dedicated variational-training path, which this harness doesn't call. Said plainly in benchmark.py rather than quietly kept in for a name that wasn't earning its place.)

Vanilla PINN
Classical fully-connected MLP + tanh. Every real weight, in every real layer, is trained together by gradient descent on the PDE + boundary loss. The textbook PINN baseline.
SIREN
Same fully-connected shape as Vanilla PINN, but every hidden neuron uses a sine activation (Sitzmann et al. 2020) instead of tanh — built for smooth, high-frequency signals.
PIELM
Physics-informed extreme learning machine. The hidden layers (dashed) are random and stay fixed — only the final linear output layer (solid) has trainable weights. Trained here by the same real Adam gradient descent as the other three (confirmed: Arena's own closed-form least-squares solver for this layer, fit_ridge, is never called anywhere in pinneapple_arena — it only applies to linear PDEs, and Burgers' u·u_x term isn't one).
XTFC
Extreme Theory of Functional Connections. The hidden basis functions (dashed, marked ×) are analytically constrained to satisfy the boundary/initial conditions exactly, not randomly fixed like PIELM — only the final linear output layer (solid) is fit.
Schematic diagrams of each architecture's real topology — illustrative of the design, not a literal render of one specific trained instance's weights.

3 The real check: accuracy rank vs. physics-aware rank

Arena's rank_by_accuracy() sorts by mean relative L2 error — its normal, unchanged behavior. physics_aware_rank() is additive on top: it flags any model whose real physics-residual exceeds the group's median + 2×std — a relative outlier test — without ever reordering the accuracy ranking itself. A relative test has a known blind spot: when one model's residual is far above the rest it inflates the group's σ and the threshold with it, so models that are all poor together, or a second poor model, can go unflagged. physics_aware_rank(..., residual_threshold=...) adds an absolute cutoff for that; this page does not set one (there is no agreed absolute value for this problem), so read the residual column directly.

flagged  ⇐  residual > median + 2·σ

The real ranking logic, not a black box

Trimmed for length; the full function lives in PINNeAPPle's pinneapple_arena.arena.
pinneapple_arena/arena.py — the real, additive physics-aware check
def physics_aware_rank(train_results, eval_results, field_names, n_std=2.0):
    # unchanged accuracy ranking -- never reordered by this function
    ranking = rank_by_accuracy(train_results, eval_results, field_names)
    residuals = {t.name: t.physics_residual for t in train_results
                 if t.physics_residual is not None}
    median, std = np.median(list(residuals.values())), np.std(list(residuals.values()))
    flagged = [name for name, r in residuals.items()
               if r > median + n_std * std]   # real statistical outlier test
    return {"ranking": ranking, "physics_residuals": residuals,
            "flagged_high_residual": flagged, ...}
