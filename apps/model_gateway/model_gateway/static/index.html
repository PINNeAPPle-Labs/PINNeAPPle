Credentials

Publishing needs the app login, the admin token, or (ONNX only) an API key. They are kept in this tab only (sessionStorage).

From a ModelRef

A pinneapple_data.contracts ModelRef: zoo:<name>, or the http(s) URI of a model behind the same API (a Surrogate Studio endpoint). Its input ranges become the validity bounds. Admin only.

ONNX graph

inputs (n, d) → outputs (n, p), float32. Declare the names and the validity bounds of every input.

Surrogate Studio model.zip

Admin only: loading it unpickles the model (checked against the sha256 in its card). Upload only models you produced.

API

Interactive documentation at /docs. The same /v1 API is served by the Surrogate Studio, so a client works against either.

Python client

Built on PINNeAPPle: pinneapple_registry.ModelGateway (versions, stages, OOD policies, run log, metrics), gateway_api, gateway_client, pinneapple_data.contracts (ModelRef), pp.zoo. One interface for physical models, with their validity range.
