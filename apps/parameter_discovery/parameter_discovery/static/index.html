the method behind the number

How this actually works

Three real steps: the physics, the joint inverse solve, and the honesty check on top of it.

1 The physics: the 1D heat equation

A thin bar starts with a hot pulse in its middle and cold, fixed-temperature ends. Heat diffuses according to the standard transient heat equation, where α is the bar's thermal diffusivity — a real material property that is, in this case, unknown:

u_t(t,x) = α · u_xx(t,x),  u(0,x)=sin(πx),  u(t,0)=u(t,1)=0

All quantities here are the standard nondimensional units for this textbook PDE test case (the same one PINNeAPPle's own reference example uses) — the point is a genuine, citable inverse problem, not a specific SI-unit material.

2 The mechanism: α as a real trainable parameter

PINNeAPPle's PINN class stores α as a real nn.Parameter inside model.inverse_params, alongside the network's own weights. The same Adam optimizer step updates both, from the same joint loss — the network and α are discovered together, not in separate stages:

loss = pde_residual + 50·conditions + 5·fit(noisy sensor data)  →  loss.backward()  →  opt.step()

That single opt.step() nudges every network weight and α in the direction that most reduces the combined error — which is exactly the live trajectory in the chart above.

3 The honesty check: could α even be known here?

A recovered number alone doesn't say how much to trust it. pinneapple_analysis.inverse_problems.sensitivity computes a real Fisher Information Matrix from the exact sensor positions used, giving a Cramér-Rao lower bound — the best possible standard error any unbiased estimator could achieve given this noise level and this many sensors:

SE(α) ≥ sqrt(1 / FIM(α))

This is run for every real result on this page, using the real noisy sensor layout actually drawn for that run — not a generic disclaimer.

The real code, not a black box

Trimmed for length; the full module is pinneapple_analysis/inverse_problems/heat_diffusivity.py.
heat_diffusivity.py — the joint inverse solve
from pinneapple_physics.pinn_solver.factory.pinn_factory import NeuralNetwork, PINN, PINNFactory, PINNProblemSpec

spec = PINNProblemSpec(
    pde_residuals=["Derivative(u(t,x), t) - alpha*Derivative(u(t,x), (x,2))"],
    conditions=[{"name": "ic", "equation": "u(t,x) - sin(pi*x)", "weight": 1.0}, ...],
    inverse_params=["alpha"],  # the unknown to be discovered
)
model = PINN(net, inverse_params_names=["alpha"], initial_guesses={"alpha": 0.5})
opt = torch.optim.Adam(model.parameters(), lr=2e-3)  # weights AND alpha, same optimizer

for step in range(n_epochs):
    loss, _ = loss_fn(model, batch)  # batch["data"] = the real NOISY sensor readings
    loss.backward(); opt.step()
    alpha_hat = model.inverse_params["alpha"].item()  # real, live estimate every step
heat_diffusivity.py — real noisy sensor data + the real honesty check
y_d_noisy = y_d_true + rng.normal(0.0, noise_std, size=y_d_true.shape)  # real Gaussian sensor noise

from pinneapple_analysis.inverse_problems.sensitivity import LocalSensitivity, IdentifiabilityAnalyzer

sensitivity = LocalSensitivity(forward_fn, noise_std=noise_std, param_names=["alpha"])
result = sensitivity.compute(theta_nominal=torch.tensor([alpha_hat]))  # real Fisher Information Matrix
ident = IdentifiabilityAnalyzer().analyze(result.fisher_information, param_names=["alpha"])
cramer_rao_se = math.sqrt(ident.a_optimality)  # real Cramer-Rao lower bound on alpha's std. error
