Most parameters barely matter. Which ones are they?

Before a calibration, an optimisation or a test campaign, know which inputs control each response, which act through interactions, and which can be fixed without changing the answer.

Sobol indices with intervalsfirst-order, total and second-order shares of the output variance, bootstrap confidence intervals
Morris screeningcheap first pass over many parameters: mean absolute effect and its spread
Effect curvesmain effects (partial dependence) and ICE curves; crossing curves mean interactions
Freeze, with evidencea parameter is frozen only if its total index is surely small, then re-checked by re-running the model

Works on a built-in benchmark, a zoo model, your ONNX model, runs done in OpenFOAM / CalculiX, or a dataset.
