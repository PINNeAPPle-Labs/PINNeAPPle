API

Everything in the page is an HTTP call; interactive documentation at /docs. Studies run as jobs (GET /api/jobs/{id}); models are served at /v1/models, the same shape as the Model Gateway. Send X-API-Key when the server requires one.

Python

Built on PINNeAPPle: pinneapple_analysis.surrogate (study, limitations, trust report), cost.equal_budget, pinneapple_registry.ModelGateway, pinneapple_data.contracts (DatasetSpec, ModelRef, StudyResult). Physics AI that says where it can be trusted.
