Three questions, kept apart

Numerical verificationWere the equations solved right? PDE residuals, finite values, readable and intact artefacts, method status.
Validation against dataDoes it match trusted reference data, and is it used inside the range the data covers? Reference error, QoIs, out-of-range queries.
Physical consistencyConservation of mass, energy and momentum; boundary and initial conditions; bounds and constraints; dimensional consistency.

Every check that runs leaves an evidence record (SHA-256 of its inputs, its outputs, start and finish time). A check that did not run is reported as not run, never as a pass. The report holds the configuration and the input hashes, so pinneapple check reproduces it locally or in CI.
