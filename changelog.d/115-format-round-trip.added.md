- **XDMF3** is read and written without loss (#115): `pinneapple_data.cae.xdmf.write_xdmf` writes one self-contained file (inline XML data, `%.17g` — the round-trip precision of a double) with points, connectivity, node and cell fields and one or several cell blocks, and `read_xdmf` reads it back **exactly**; an upload of the same kind is now routed to it by `io.read_any` with no extra installed. An XDMF whose data lives in a companion HDF5 file is refused with the sentence naming meshio, instead of being half-read.
- **A CGNS writer** (`cfd_formats.cgns_writer.write_cgns` / `mesh_to_cgns`), through the same CGNS/HDF5 mapping the reader uses, so the circle closes: what `read_cgns_mesh_and_fields` reads, this writes, and the round trip is exact. The files pass the CGNS project's own `cgnscheck` validator with **0 errors** — which is how the attribute encoding was pinned down (`label`/`name` 33-byte NULL-terminated, `type` exactly `len+1`; a first version segfaulted the validator).
- **STEP and SSP are declared, not pretended** in `docs/dev/PHYSICS_AI_INTEROP.md` §5.1, with the reason: STEP needs an OpenCascade binding, and SSP is a system/parameter container next to the FMU support, not a field format.
