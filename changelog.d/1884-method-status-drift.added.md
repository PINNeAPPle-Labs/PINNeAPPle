- `python scripts/build_method_status.py --check` compares a fresh scan of the test suites with the committed `pinneapple_catalog/method_status.json` and prints the drift — the status changes, the tests newly credited or no longer credited, the counts — with the command that refreshes it; `--report` prints the same and exits 0, which is how the CI step runs it (informational, never failing). The reason is that the snapshot is a generated artifact two readers treat as a contract: the `PC901` rule of `pinneapple_check` and the fixtures in `examples/physics_check/fail`, so a refresh that moves a status has to move both in one reviewable commit. The snapshot is refreshed here: the solve guide added in #47 credits one more test to S2, and the scan now covers 682 test files and 6395 test functions instead of 675 and 6337 — no status changes, so no fixture moved (issue #1884).
