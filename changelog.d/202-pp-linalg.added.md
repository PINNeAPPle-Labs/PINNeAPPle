- `pinneapple_analysis.linalg` is the linear-algebra layer behind `pp.linalg` (issue #202, roadmap X18): `LinearOperator` (a shape, a `matvec` and, when it is given, an `rmatvec` — everything else here takes a matrix or an operator as the same argument, and an operator built without `rmatvec` refuses `.adjoint()` rather than transposing a map that may not be symmetric), `pod` (POD by SVD, with the energy captured, the numerical rank of the data, the coefficients and the reconstruction error measured on the snapshots that produced the basis), `modal_analysis` (eigenvalues, frequencies in Hz, damping ratios, mode shapes, modal participation, the condition number of the eigenvector basis, and `LINALG.NEAR_DEFECTIVE` instead of quotable eigenvalues for a defective matrix; for a `LinearOperator` the modes are Ritz values from `arnoldi`, flagged `ritz_approximation` with each mode's measured residual), `arnoldi` (the Krylov basis, the Hessenberg matrix, the Ritz values and their residuals, and the breakdown that says the subspace is invariant), `condition_estimate` (the Hager-Higham 1-norm estimator — a lower bound from a handful of solves, for a matrix or a matrix-free operator with a `solve` callable, with the exact value reported alongside when the matrix is dense) and `adjoint_sensitivity` (`d(c^T x)/dp` for `A(p) x = b(p)` by one adjoint solve for every parameter, each value checked against a central difference of the re-solved system). Measured: on a two-degree-of-freedom mass-spring-damper the frequencies are `sqrt(3 ± sqrt 5)` rad/s to 1e-3 and each eigenvalue is a root of the characteristic polynomial to 1e-12; the POD truncation error equals Eckart-Young's `sqrt(1 - captured)` with the centred norm; the condition estimator lands between 0.46 and 1.0 times `np.linalg.cond(A, 1)` on random matrices and reaches it exactly on a Hilbert matrix and on a diagonal one; the adjoint derivative agrees with the finite difference to 1e-5 while using one forward and one adjoint solve instead of two per parameter. 25 tests in `tests/pinneapple_analysis/test_linalg_layer.py`. `condition_number` (the exact 2-norm value from #1061) is re-exported, and `pinneapple_flow.coverage` carries the reason this layer is not itself a flow node.
