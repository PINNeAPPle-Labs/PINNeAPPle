- A blocking end-to-end tier of ten flows (`tests/e2e/`, `make e2e`, and a must-pass step in the tests workflow): each flow goes from an input a user has — a problem, a differential equation written as text, a parameter space, a plant record — to an artifact they keep (metrics against a reference, an `experiment.json` that reloads into the same predictions, a heat-flow comparison, a governed model card), through the public API only. The list of ten is a contract checked against the folder, and each flow enforces its own wall-clock budget, so "under ten minutes in total" is a property and not a hope; measured at about five seconds together. Nothing in the tier may skip — a missing dependency fails it, because a skipped flow in a blocking tier reads as a pass (issue #37).
- Two bugs the new tier found, both fixed: `PhysicalProblem.with_parameters()` updated the parameter but left the copy in `pde.params` at the value the preset shipped, so `to_pde_spec()` — which writes the current values — described a different problem from the one just built and `from_pde_spec(to_pde_spec(problem))` came back with a different fingerprint; and `pinneapple_data.contracts.validate()` refused a contract object with "not a PINNeAPPle contract (kind=None)", answering the most natural call (`validate(DatasetSpec.load(path))`) with a confusing message — it now accepts the object, its dict, or the path (issue #37).
