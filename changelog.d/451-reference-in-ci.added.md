- The module reference (`docs/org/reference/`) is now gated in CI, not just generated by hand: the `Module reference` workflow rebuilds it and fails a pull request whose committed copy is stale, runs the curated examples of the packages a pull request touches (`--check`, no figures written), reruns every example weekly and opens a pull request when an output actually changed, and `Deploy Docs` regenerates the reference before `mkdocs build`. Both scripts take `--check` for local use, and `CONTRIBUTING.md` documents the two commands.
