- `docs/guides/solve_a_problem.md` is the missing task-oriented entry point for "solve": one runnable example that describes a Poisson problem, solves it with FEM and with a PINN, and compares both against the exact solution in about ten seconds, followed by a table pointing at the guides for the other goals (method choice, inversion, design, validation, visualisation, benchmarks, CI). `tests/test_solve_guide.py` runs the example so the guide cannot drift (issue #47).
