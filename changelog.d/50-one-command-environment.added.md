- A `Makefile` gives the development environment one command per job: `make setup` (a `.venv` with the package installed editable plus the `[dev]` extras), `make test` (the fast suite, ~30 s), `make test-full`, `make lint` (the `E9` selection CI enforces), `make lint-backlog` (the wider ruff selection declared in `pyproject.toml`, ~21,000 findings, which is a backlog rather than a gate), `make gates` (changelog, module reference, licensing), `make docs`, and `make clean`. All of them take `PY=` to point at another interpreter, and `make setup TORCH_INDEX=https://download.pytorch.org/whl/cpu` avoids the CUDA build of torch inside a container (issue #50).
- `.devcontainer/devcontainer.json` defines the same environment for a codespace or VS Code Dev Containers: a Python 3.12 image whose `postCreateCommand` is `make setup`, so the container cannot drift from `CONTRIBUTING.md` (issue #50).
