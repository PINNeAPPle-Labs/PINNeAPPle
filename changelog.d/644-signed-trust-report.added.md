- A trust report can be signed together with the model and the inputs it describes: `pinneapple_analysis.trust.SignedTrustReport` records the physics residual in the DSSE-signed payload and **recomputes it from the loaded model and inputs** on every verification, so a stale, mistyped or fabricated number fails even when the payload is correctly signed. The model is serialised as a state dict and the grid residual is the field card's grid check (`laplace`, `poisson`, `heat`).
- Measured: 39184 single-bit flips at every byte position of a 4898-byte bundle all fail verification, and a bundle whose residual was changed and then re-signed with the right key fails with `ResidualMismatch` naming both numbers. Guide: `docs/guides/signed_trust_report.md` (#644).
