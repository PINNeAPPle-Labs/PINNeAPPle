- The wide suite now blocks in parts (`tests/tier_shards.json`, `scripts/tier_shards.py`, and a `tier-shards` workflow that runs on every pull request): `tests/` is split into 23 shards, and a shard becomes **blocking** when a recorded measurement shows it green — then every pull request runs it and any failure fails the build. A shard that is not blocking carries a reason and the ceiling the nightly job allows, instead of the single number that used to cover the whole suite. `--check` is the gate and it refuses a test file that belongs to no shard (a new test cannot land unclassified), a blocking shard with no measurement behind it, a blocking shard whose ceiling is not 0, a non-blocking shard with no reason, and a path that matches nothing; `--promote <shard>` is how a shard earns its place — it runs the shard first and refuses to promote one that fails, recording the date, the counts and the seconds in the declaration. `--run-blocking` is what the pull-request job runs and `docs/dev/test_shards.md` is generated from the declaration, so the page and the gate cannot disagree (issue #90).
- Two fixes that promoting the shards turned up: `scripts/validate_provenance.py` now ignores scratch directories (a `_`-prefixed folder such as `_work`/`_out`/`_runs` holds what a run wrote this time, and asking it for provenance made the gate depend on whether someone had run an example), and `tests/pinneapple_tools/test_physicsnemo_sym_backend.py` skips instead of failing when `nvidia-physicsnemo.sym` is absent — the old guard called `importlib.util.find_spec("physicsnemo.sym")`, which *raises* when the parent package is missing, so in an environment without the package the whole module failed and read like a bug in the backend (issue #90).
