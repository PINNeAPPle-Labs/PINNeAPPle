- The repository's own backlog is now a generated page inside the repository (`docs/backlog.md`, with the snapshot it is rendered from in `docs/backlog.json`): every issue of `PINNeAPPle-Labs/PINNeAPPle` that carries a scope label, split into this year and the next cycle, grouped by its `area:` label, with a checked box for a closed issue and the priority and effort labels beside the title. It exists because the list of what is in scope used to live outside the repository, where it drifts; now it is derived from the issues themselves. `python scripts/backlog_report.py --fetch` refreshes the snapshot from GitHub, `--write` regenerates the page from it, and `--check` (the CI gate, offline and deterministic) refuses a page that does not match its snapshot, an issue listed twice, or an issue in the snapshot with no scope label. The page also says how many issues sit outside the scope, so the absence is visible rather than silent.
