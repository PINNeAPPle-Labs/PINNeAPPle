- `pinneapple_physics.pinn_solver.compiler.dict_collate` stacks the per-sample dicts of `SingleBatchDataset` (`x_col`, `x_bc`, ...) again. It used to hand them to `collate_pinn_batches`, which only knows the `collocation` / `conditions` / `data` layout and returned an empty dict, so the benchmark runner `run_models_from_cfg` received empty batches (#1129).
- The turbulence-closure residuals (`KOmegaSSTResiduals`, `SpalartAllmarasResiduals`, `WALEResiduals`) no longer raise on a field that is linear in the coordinates, for example Couette flow: the derivative of a graph-free constant is zero (#1129).
