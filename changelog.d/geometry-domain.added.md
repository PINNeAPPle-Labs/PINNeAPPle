VeriPhysics now offers `validated_domain.ValidatedDomain` for joint parameter screening with explicit model identity, normalized local coverage, independent reference errors, physics tolerances and uncertainty limits. Adding a parameter requires a new schema and new evidence. `extend` preserves failed observations; `prioritize` identifies unsupported candidates for additional simulations. Pass `validated_domain` and `geometry_query` to `build_applicability_map` to expose the result. Training intervals alone are no longer labeled verified. Local marginal bracketing is a heuristic, not a convex-hull or certified error bound; callers must compute and authenticate independent references, physical checks and calibrated uncertainty. This API does not execute solvers or enforce inference rejection automatically.
