- `pinneapple_simulation.external_solvers.mujoco` now targets **MuJoCo 4.0** (2026-11-06) and keeps the 3.17 line on Python 3.10. The bridge gains a recorded `MuJoCoTrajectory` (energy, contacts, body lookups) with UPD export, six analytic checks (`validate()`: free fall, pendulum period, sliding friction, gravity torque, torque-free spin, resting contact), `BatchRunner` on `mujoco.batch` (thread-pool rollouts with per-environment mass/friction randomisation, no JAX), `MuJoCoRobotSim` (the `RobotSim.run(...) -> RobotRun` interface, so the same robot study runs on MuJoCo and Newton and is checked against `pinneapple_simulation.multibody`), and `MjSpec` loading. MJX is detected through the new `mujoco-mjx` package: in 4.0 it is no longer inside the `mujoco` wheel, so `pip install "pinneapple[mujoco_mjx]"` installs it and the Arena runners report it instead of failing. Extras now install `mujoco>=4.0` on Python >= 3.11 and `mujoco>=3.17,<4` on 3.10.
