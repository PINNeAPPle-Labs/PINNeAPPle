`pinneapple_veriphysics`: the **validation loop** — a use case, its evidence, its maturity and the person who signs it, as one auditable object (`usecase`, `findings`, `maturity`, `validation_case`, `dossier`; guide `docs/guides/validation_loop.md`). `usecase.ValidationProfile` declares the use before any check runs (decision, decision quantity, tolerance, required independent reference, consequence of being wrong, with the preset tolerances labelled illustrative and never a norm). `findings` explains every signal with four deterministic answers — what happened, why it matters, what is still unknown, what to do next — from a versioned rule table, so no LLM writes the explanation and a check that did not run is never a pass. `maturity.assess_maturity` reports two independent axes (scientific maturity and industrial readiness) with five verifiable levels each and the action that closes every gap. `validation_case.ValidationCase` is built from what the other modules produced (`checks_from_trust_card`, `checks_from_lab_report`, `checks_from_ledger`, `applicability_facts_from_map`), immutable and append-only: every change seals a revision whose snapshot hash makes tampering detectable, the four states (`validated` / `review required` / `failed` / `unvalidated`) follow a documented precedence where a technical failure cannot be overwritten by a reviewer, `validated` requires an expert approval with a documented scope, and a required reference or mandatory check that is absent leaves the case `unvalidated`. `dossier.ValidationDossier` renders the case (declared use, findings, every check including those that did not run, reference errors against the tolerance, applicability, uncertainty and its limitations, decisions, maturity with open gaps, provenance, revision history) as text, Markdown or self-contained HTML, with a disclaimer on the document itself that it is not a certification. `applicability.build_applicability_map` also accepts `parameter_ranges`, so a model trained across a parameter interval records that interval as its verified range instead of a single point.
