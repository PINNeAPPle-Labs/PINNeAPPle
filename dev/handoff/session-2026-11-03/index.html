    1. Working rules (keep them)¶

    Reporting - Report to the owner in Portuguese. - Never present a number that was not measured. Always state what could not run (for example "not run: no OpenFOAM here").

    Issues - Create the issue before solving anything (one issue per piece of work; sub-issues for families of work).

    Merging a PR - Wait for green CI. - Run git merge-tree --write-tree origin/main origin/<branch>. - Review the diff. - Rewrite the PR body without the "Generated with Claude Code" footer. - Squash-merge with the full 40-character expectedHeadSha. - Merges that depend on the owner's authorization are authorized.

    Branch (library) - Library branch: claude/clever-archimedes-sajlck. No force-push. - One PR at a time on this branch. Develop the next work on local wip/* branches and apply it after the merge. - After each merge, reset the branch:

    git fetch origin
git checkout -B claude/clever-archimedes-sajlck origin/main
git merge -s ours origin/claude/clever-archimedes-sajlck -m "Merge the merged branch history (ours)"
git push -u origin claude/clever-archimedes-sajlck

    Then apply the wip work with git diff <old-tip> wip/<name> | git apply --3way.

    Commits and PRs - Commit trailers: Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com> and Claude-Session: https://claude.ai/code/session_011DQdC6k6gMAY3AdDKmmdD8. - No model IDs in commits or PRs.

    Code and CI - Client data never goes to public repositories. - Never weaken a CI gate. For example, the 160 000 B first-load page budget of the engineering app stays as it is. - Features live in the library; apps only use them. - Run ruff check <the files you changed> last, before pushing. - Never ruff check --fix <directory>: it rewrote six unrelated pinneapple_veriphysics files once and had to be reverted.

    Processes - Kill processes by PID, never pkill -f. - Use timeout -s KILL for gmsh. - Use python -m pip. - The missile-defence prototype (#1153–#1158) must never be continued.

Run that case in OpenFOAM. - Flow cache: flow runs are cached by params, so a code change does not invalidate the cache (pre-existing behaviour). Use --no-cache.
