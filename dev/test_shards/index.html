    Promoting a shard¶

    python scripts/tier_shards.py --measure <id>    # see what it does today
python scripts/tier_shards.py --promote <id>    # runs it again and, if green, makes it blocking

    A shard is promoted by a measurement, never by opinion: --promote refuses a shard that fails, and the record it writes (date, counts, seconds) is what the gate reads.
