**Reporting**
- Report to the owner in Portuguese.

**Merging a PR**
- Wait for green CI.
- Run `git merge-tree --write-tree origin/main origin/<branch>`.
- Review the diff.
- Rewrite the PR body without the "Generated with Claude Code" footer.
- Squash-merge with the full 40-character `expectedHeadSha`.
- Merges that depend on the owner's authorization are authorized.

**Branch (library)**
- Library branch: `claude/clever-archimedes-sajlck`. No force-push.
- One PR at a time on this branch. Develop the next work on local `wip/*` branches and apply it after the merge.
- After each merge, reset the branch:

  ```
  git fetch origin
  git checkout -B claude/clever-archimedes-sajlck origin/main
  git merge -s ours origin/claude/clever-archimedes-sajlck -m "Merge the merged branch history (ours)"
  git push -u origin claude/clever-archimedes-sajlck
  ```

  Then apply the wip work with `git diff <old-tip> wip/<name> | git apply --3way`.

**Commits and PRs**
- Commit trailers:

  `Claude-Session: https://claude.ai/code/session_011DQdC6k6gMAY3AdDKmmdD8`.

**Code and CI**
- Client data never goes to public repositories.
- Never weaken a CI gate. For example, the 160 000 B first-load page budget of the engineering app stays as it is.

**Processes**
- Kill processes by PID, never `pkill -f`.

- **Litho FNO as the ILT imager:** the force-surrogate path of `correct_mask` trains at the clip's N (128). That is about 4× the 64² cost measured (171 s), and the operator only models best focus. Not measured end to end.
- **Wing VLM:** it sits about 7 % below lifting-line theory at AR 6 and converges to it at high AR, which is consistent with lifting-surface theory. It has not been compared with a published lifting-surface value.
- **Reactor presets:**
  - The o-xylene bed has a single reaction and no pressure drop, as in the source example (both stated in the output).
  - The 673 K hot-spot limit was set in this session; it is not from the source.
  - The propylene-glycol *cooled* case was not compared with Fogler (only the adiabatic one reproduces X = 0.85 at 613 °R).
- **Ahmed design:** unverified, because no recorded CFD run is within 0.05 (unit cube) of the optimum. Run that case in OpenFOAM.
- **Flow cache:** flow runs are cached by params, so a code change does not invalidate the cache (pre-existing behaviour). Use `--no-cache`.
