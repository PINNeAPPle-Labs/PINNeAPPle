## Summary

An object is described as a voxel field with a material state per voxel, the description is encoded, transmitted as a bit stream and reconstructed, and the experiment measures two things: the geometric and material error of the reconstruction as a function of the bit budget, and the information bill for a stated resolution. The physical content is the accounting, not the transport: the bit count for a resolution, the compressor's efficiency against the entropy of the description, and the order-of-magnitude gap between any achievable payload and the atom count of a macroscopic object.

## Question

For a stated object and a stated voxel resolution, what is the minimum bit stream that reconstructs the object within a stated geometric and material error, and how does that bit count compare with the information-theoretic content of the same object described at atomic resolution?

## Why run it

- The question is answerable exactly as posed, and the answer is a number with a factor that speaks for itself, which is more useful than an argument about whether teleportation is possible.
- The encoding side produces something reusable: a voxel-field codec with a stated rate-distortion curve, which is directly applicable to the geometry and field data the rest of the library already stores in zarr.
- The library has the geometry, the zarr storage and the error mapping, so the build is the codec and the accounting — a realistic single-issue scope.

## Physical model

The object is a scalar-and-label field on a voxel grid: a material identifier per voxel (a small label set, eight materials is enough) plus, for one material class, a continuous field. Reconstruction error is measured in two ways.

**Geometric.** The symmetric surface distance between the original and reconstructed isosurfaces, sampled at a fixed density: mean and 95th percentile in millimetres, plus the volumetric intersection-over-union of the material masks.

**Material.** The per-voxel label error rate, and for the continuous field, the relative `L2` error.

The information accounting has three reference points, and the experiment's credibility depends on reporting all three.

1. **Rate-distortion of the codec.** Bits per voxel against reconstruction error, as a curve, from a family of codecs (lossless label coding, a transform coder, and a learned or downsampled representation).
2. **The Shannon bound for the discrete description.** The empirical entropy of the label field, and the conditional entropy given the neighbour context the codec uses, which bounds how far the codec can be improved.
3. **The atomic description.** A human body contains of order `7 x 10^27` atoms, so a description at one bit per atom is of order `10^27` bits, and at the 3 to 4 bits per atom needed to specify the element and a coarse state, nearer `10^28`. The voxel description at 1 mm resolution for the same volume is of order `10^8` voxels times the label bits, i.e. some `10^9` bits. The ratio between the two is the result the reader needs.

Validity and omission: this is classical information theory applied to a geometric description. It says nothing about whether a physical object can be assembled from a description, about the quantum state of the atoms, or about the energy of assembly. The no-cloning restriction applies to unknown quantum states and not to a classical description prepared from measurements, and the report must state this precisely rather than implying the classical route is forbidden.

## Geometry and inputs

Objects: a bracket-like mechanical part, a hollow shell with internal channels, and a scanned surface from the `scan` path of the scene builder, so there is one synthetic and one measured-like case. Resolutions: voxel sizes of 4, 2, 1 and 0.5 mm, giving grids from about `10^5` to `10^7` voxels. Bit budgets: from 0.05 to 8 bits per voxel. Material labels: eight, with a stated per-material distribution.

## What is missing (the work)

1. **A voxel-field codec**: `pinneapple_data/codec/voxel.py` with `encode(label_field, field=None, budget_bits_per_voxel)` and `decode(stream)` returning the rate-distortion-optimal representation at that budget. Three stages are needed: a lossless label coder (context-modelled arithmetic coding), a transform stage for the continuous field, and a downsampling path for the lowest budgets. None of this exists.
2. **An entropy accounting layer**: `entropy(label_field, context_order)` and `entropy_bound(...)`, so the codec's efficiency against the empirical entropy is a reported number and not assumed.
3. **A reconstruction-error metric that is geometric**: symmetric surface distance and intersection-over-union, on the isosurface, since `error_map` compares point sets and not surfaces. This belongs beside the codec, with the point-set version from `error_map` used for the field error.
4. **A description-size calculator** that takes a resolution, an object class and a material label set and returns the bit count, plus the atomic reference for the same mass and element mix, with the assumptions written down. This is small and is the heart of the honest result.
5. **A budget gate**: a refusal when a requested bit budget is below the entropy floor for the stated error, returning the smallest budget that meets the tolerance rather than a misleading reconstruction.

## Experiment protocol

1. Voxelise the three objects at four resolutions; check the voxelisation against the analytic volume of the synthetic part and against the mesh volume for the others, within a stated tolerance.
2. Lossless baseline: arithmetic coding with context orders 0 to 3; report bits per voxel and the entropy at each order, so the coding gap is visible.
3. Rate-distortion sweep: 12 budgets by 3 objects by 4 resolutions = 144 encodes; for each, the geometric error, the label error and the field error.
4. Decode timing: measure the stream throughput per core, so the "transmission" side has a rate and not just a size.
5. Visual inspection of the smallest and largest budgets per object, with the error field rendered on the reconstructed surface.
6. Information comparison: compute the description size at each resolution and the atomic reference, and present the ratio.
7. Compute budget: minutes per encode at the largest grid; the whole campaign is order 10^1 CPU-hours.

## Baselines, references and verification

- The analytic entropy of the label field at each context order is the codec's reference; the achieved bits must sit between the entropy and the entropy plus a stated redundancy.
- The voxel volume against the analytic or mesh volume is the geometric-consistency check.
- The lossless coder must round-trip exactly at the highest budget, which is a hard correctness test, and any case that does not is a bug and not a datapoint.
- Baselines the codec must beat: naive gzip-style compression of the raw grid, and uniform downsampling followed by nearest-neighbour upsampling at the same bit budget. A codec that loses to both has no result.
- The atomic reference is a stated calculation, not a citation of a video; the assumptions — mass, mean atomic number, bits per atom — are listed in the report.

## Metrics

- Bits per voxel `b`, and total payload size in bytes, per object and resolution.
- Geometric error: mean and 95th percentile symmetric surface distance, mm.
- Volumetric overlap: intersection-over-union of the material masks, dimensionless.
- Label error rate, percent; field relative `L2` error, percent.
- Coding efficiency `eta = H / b`, where `H` is the empirical entropy at the codec's context order, dimensionless.
- Description ratio `R = B_atomic / B_voxel`, the order-of-magnitude comparison, reported with the exponent and the assumptions.
- Decode throughput, voxels per second per core.

## Deliverables

- The voxel codec, the entropy accounting and the geometric error metric as importable modules with round-trip tests.
- The rate-distortion curves for all three objects, as data and figures.
- The payload size tables per resolution, with the atomic comparison alongside, as CSV.
- Reconstruction renders at the smallest and largest budgets, with the error field mapped on the surface.
- A `pinneapple_lab` manifest per encode, with the object, resolution, budget, seed and code revision.
- A short note in the report on what the number excludes: assembly energy, quantum state, and the control problem of placing atoms.

## Acceptance criteria

- The lossless coder round-trips exactly for every object at every resolution, verified bit for bit.
- The achieved bits per voxel are never below the empirical entropy at the same context order; a violation indicates a model error and stops the result.
- The codec beats both baselines — gzip-style compression and uniform downsampling — at equal bit budget on the geometric error, for every object, or the report states the case and the margin where it does not.
- The voxelisation volume matches the analytic or mesh volume within 1 percent at the finest resolution.
- The description ratio is reported with the exponent and with every assumption listed, and the atomic reference is computed in the same run rather than quoted.
- The report states that the number excludes assembly energy and quantum state, in the same section as the ratio.

## Realizability and evidence class

`PLAUSIBILITY_CLASS`: `established` as an information and coding exercise; `hypothetical` for reconstructing the described object physically, since no assembly mechanism is modelled; `fictional` for the transport of a person. Axes this run fills: `mathematical_consistency` (entropy bounds, exact round-trip, volume checks), `numerical_stability` (deterministic encode, decode given the same stream), `physical_plausibility` (the atomic reference and the coding efficiency against the entropy bound), `uncertainty_sensitivity` (resolution and label set variation). `experimental_validation` and `technological_feasibility` are not assessed: no assembly is attempted and the energy of assembly is not computed.

To move up one class, in order: (1) an assembly mechanism with a stated throughput and error rate, which is the missing physical half and would turn a description into a construction; (2) an energy accounting for assembly at the stated resolution, which at atomic scale is the number that decides everything; (3) a quantum-state argument, since a classical description of a macroscopic object's quantum state is not obtainable, and this issue deliberately restricts itself to the classical description; (4) a demonstration at a small but non-trivial scale, a few thousand atoms assembled from a description, which would be a laboratory result and not a simulation.

## Risks and failure modes

1. **The ratio is presented as an argument for or against.** Mitigation: the ratio is a number with its assumptions listed; the report states it is an order-of-magnitude comparison and not a feasibility verdict.
2. **The learned or downsampling codec is compared unfairly with the lossless one.** Mitigation: all codecs are compared at equal bit budget on the same error metric, with the budget enforced rather than reported.
3. **The geometric error metric is sensitive to sampling density and the numbers are not comparable across cases.** Mitigation: the sampling density is fixed per object and reported, and the surface distance is computed on a common reference tessellation.
4. **The entropy bound is misapplied to a non-stationary field.** Mitigation: context order is reported with every efficiency number, and the efficiency is not claimed beyond the orders tested.
5. **The atomic reference is asserted rather than computed.** Mitigation: it is computed in the same run from the stated mass and element mix, and the sensitivity to the bits-per-atom assumption is given for two values.

## Out of scope

- Any faster-than-light or transmission-medium claim; the transport is a file copy.
- Assembly energy, atom placement and any physical reconstruction mechanism.
- Quantum state transfer, which is the subject of D19.
- Compression of the continuous field beyond the single transform family tested.

- Bennett, C. H. (1973), "Logical reversibility of computation", *IBM Journal of Research and Development* — the reversible-computation counterpart, relevant to the energy accounting excluded here.
- Wootters, W. K., Zurek, W. H. (1982), "A single quantum cannot be cloned", *Nature* — the restriction that applies to unknown quantum states and not to a classical description prepared from measurements.
- Bekenstein, J. D. (1981), "Universal upper bound on the entropy-to-energy ratio for bounded systems", *Physical Review D* — the information-versus-energy bound that any physical description of an object is subject to.
