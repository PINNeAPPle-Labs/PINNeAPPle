# Examples as flows

Every `examples/*` folder, the flow that reproduces it in Flow Studio (*Open... -> Examples*) and the outcome of running that flow. Generated by `python -m pinneapple_flow example-flows doc` from `pinneapple_flow/flows/examples/` (the flows), `inventory.json` (statuses and reasons) and `measured.json` (written by `example-flows run`: every number below was measured by a run of the flow, none is typed in). `tests/test_flow_examples.py` fails when a folder has neither a flow nor a reason.

Statuses: **runs** (the flow runs in its full configuration), **runs-quick** (it runs in its documented quick configuration, `meta.quick` of the flow; the full one is too long for this machine), **needs X** (a tool that is not installed here), **not_convertible** (the reason says why).
