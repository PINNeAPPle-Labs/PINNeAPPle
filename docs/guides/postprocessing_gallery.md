# Post-processing gallery: six reference pictures

Roadmap item #62. The same flow, seen six ways, generated by one script from an analytic field — so the pictures need
no dataset, no solver and no network, and a change in the defaults shows up in all six at once.

```bash
python scripts/gallery_postprocessing.py                       # docs/assets/postprocessing
python scripts/gallery_postprocessing.py --out /tmp/g --size 900x600
```

The flow is the ABC solution of Euler (Arnold-Beltrami-Childress) on a 2π box: steady, divergence-free and chaotic, so
the streamlines fill the volume instead of collapsing into a plane.

## The six

| Picture | What it is for |
|---|---|
| `01_slice` | a slice coloured by speed with the vectors on it: the plane a report opens with |
| `02_isosurface` | `|u| = 1.4`: the surface that separates the fast core from the slow outside |
| `03_streamlines` | pathlines from a plane of seeds: direction without a time axis |
| `04_tubes` | the same lines as tubes, seen at an angle: the one that reads as a surface |
| `05_vectors` | arrows scaled by speed, where the eye can follow direction |
| `06_composite` | outline, slice and isosurface together: the picture with depth |

## Conventions

- White background and the house palette, so the gallery belongs with the rest of the documentation.
- The colour map is `cfd_sequential`, the same one `field_cmap("speed")` returns: one quantity, one colour.
- Seeds sit on a plane off the diagonal — the diagonal passes through the stagnation point of the ABC flow, and a
  gallery whose streamlines all meet at one point teaches nothing.

## Regenerating

The script writes all six; `python scripts/gallery_postprocessing.py` rewrites them in place. It needs `pyvista` and
an off-screen renderer (`pip install "pinneapple[pyvista]"`); on a machine without a GL context the test that runs it
skips instead of failing, and the images stay as they are.
