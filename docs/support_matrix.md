**The rule.** A cell is green only when a run of `scripts/check_matrix.py` from that environment is recorded in the file. Being declared is not being green: the page says *executed* for the cells somebody ran and *declared* for the ones nobody did, and never the other way around.

## What the smoke runs

The same steps in every environment, chosen because they are the ones a torch or numpy change breaks first, and because they finish in seconds:

| Step | What it does |
|---|---|
| `imports` | import numpy, scipy and torch, and read the versions |
| `facade` | import pinneapple as pp; pp.info() runs and pp.__version__ parses |
| `preset` | pp.get_preset('poisson_2d') builds a problem spec with a PDE, conditions and fields |
| `stability` | pinneapple_stability.stability() classifies a core module as core |
| `autograd` | a PINN forward, a gradient in the inputs and one Adam step through torch autograd |

Nothing in it trains a network to convergence or solves a 3-D case: those are hours, and the question here is whether the environment runs the library at all.

## Running the check

```bash
python scripts/check_matrix.py              # is this environment in the matrix? + the smoke
python scripts/check_matrix.py --json       # the same, machine-readable
python scripts/check_matrix.py --record     # write this passing run into support_matrix.json
python scripts/check_matrix.py --markdown   # regenerate this page
```

The exit code is `0` when the environment is in the matrix and every step passed, `2` when the smoke passed but the environment is outside the matrix (a newer Python, a torch older than the floor, no torch), and `1` when a step failed.

## How to close a declared cell

A declared cell becomes executed with one command, in an environment of that combination:

```bash
python3.12 -m venv /tmp/m && /tmp/m/bin/pip install -e .
/tmp/m/bin/python scripts/check_matrix.py --record --note "ubuntu 24.04, ARM runner"
```

The plan of 2026-10-03 runs the matrix in GitHub Actions, which is off in this repository for billing reasons, so the Linux and Windows cells need a machine or a runner outside it. Until then they stay declared on this page, which is the honest reading of them.
