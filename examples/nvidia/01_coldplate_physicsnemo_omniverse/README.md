# 01 Cold plate: PINNeAPPle + PhysicsNeMo + Omniverse

**What.** A 100 mm x 100 mm cold plate with copper inserts (400 W/m/K) in an aluminium base (100 W/m/K), 2 MW/m^3
of heat (100 W in a 5 mm plate), edges at the 300 K coolant. Steady conduction `-div(k grad T) = q`.

**Why.** A surrogate that looks right (1.7 % error) can still break the physics a thermal engineer relies on (energy
balance, the bound on its own error). PINNeAPPle checks the PhysicsNeMo model's fields without a reference and
writes the verdict into the OpenUSD scene, so whoever opens it in Omniverse sees the decision next to the colours.

| Step | Who | Ran here |
|---|---|---|
| layouts, finite-volume data, checks, trust decision | PINNeAPPle (`operator_benchmarks.darcy_2d`, `darcy_checks`) | yes |
| FNO training and inference | PhysicsNeMo `physicsnemo.models.fno.FNO` via `pinneapple_neural.physicsnemo_bridge` | yes (CPU) |
| USD stage: `temperature`, `conductivity`, `estimated_error` primvars, `displayColor`, `pinneapple:trust:*` | OpenUSD (`usd-core`) via `pinneapple_tools.nvidia.omniverse` | yes, validated with `pxr.UsdValidation` |
| RTX render in Omniverse Kit / USD Composer | Omniverse | **no** (needs Omniverse and an RTX GPU): `results/kit_render.py` |

```bash
pip install nvidia-physicsnemo usd-core
python examples/nvidia/01_coldplate_physicsnemo_omniverse/run.py          # ~3 min on 4 CPU cores
python examples/nvidia/01_coldplate_physicsnemo_omniverse/run.py --smoke  # seconds
```

## Results (this run: 4-core Xeon 2.1 GHz, no GPU, PhysicsNeMo 2.2.2, torch 2.14.1, usd-core 26.11)

- FNO (2.37 M parameters), 150 s of training (2736 steps, 54.7 epochs), 400 training / 50 held-out layouts, 32 x 32.
- Held-out relative L2 of `T - T_c`: **1.73 %**; worst hot-spot error **0.22 K**.
- **Decision: REJECT.** The certified residual bounds (energy 0.19 vs limit 0.10, L2 0.29 vs 0.05) and the energy
  balance (net boundary heat flow vs heat generated: 8.2 % vs 2 %) fail on most layouts; boundary condition,
  maximum principle, reference error and training envelope pass. The reference solver's own fields pass every check
  (APPROVED), so the checks are not the problem: the surrogate's fields are accurate on average but do not conserve
  energy, which matters when the plate's heat rejection is what you design.
- USD: `coldplate.usda` (one mesh, four primvars, trust attributes) passes all 30 OpenUSD validators.

Figures in `results/`: `architecture.png`, `fields.png` (k, reference, FNO, true error, error estimated from the
residual alone), `training.png`, `checks.png`, `usd_preview.png` (the stage read back with OpenUSD and drawn by
matplotlib; not an RTX render). `summary.json` and `run_info.json` hold every number and the environment. The
`.usda` is regenerated by the script and not committed.
